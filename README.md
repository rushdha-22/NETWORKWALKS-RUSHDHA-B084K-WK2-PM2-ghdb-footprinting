# W2-PM2 – Footprinting & Reconnaissance with Google Hacking Database (GHDB)

## Project Overview

This practical cybersecurity exercise explores the use of the **Google Hacking Database (GHDB)** and Google Dorking techniques for information gathering and footprinting. The activity focuses on understanding how specially crafted search queries can identify publicly indexed information and potentially exposed resources.

The exercise also highlights the security risks associated with misconfigured devices and information unintentionally made accessible through search engines.

## Objectives

- Understand the purpose and functionality of the Google Hacking Database.
- Explore Google Dorking techniques for targeted information discovery.
- Identify examples of publicly indexed and potentially exposed resources.
- Understand the security implications of exposed internet-connected devices.
- Develop awareness of responsible OSINT practices and ethical reconnaissance.

## Tools and Technologies

| Tool | Purpose |
|---|---|
| Google Search | Conduct targeted searches using Google Dorks |
| Google Hacking Database (GHDB) | Explore search operators and reconnaissance techniques |
| Web Browser | Review publicly indexed search results |

## Practical Tasks

### Task 01 – Exploring Exposed Security Camera References

The first activity involved exploring Google Dorking techniques related to publicly indexed security camera resources.

The exercise demonstrated how search operators can reveal information about internet-connected devices and highlighted the risks associated with insecure configurations and unintended public exposure.

**Security consideration:** Any potentially exposed camera resources must be handled responsibly. This repository does not publish camera URLs, private video feeds, access credentials, or other sensitive information.

### Task 02 – Google Dorking and Search Query Exploration

The second activity involved experimenting with targeted Google search queries to understand how search operators can narrow results and identify specific types of publicly indexed information.

This demonstrated how search engines can be used as an OSINT resource during the reconnaissance phase of a security assessment.

## Key Learning Outcomes

- Gained practical awareness of Google Dorking and GHDB.
- Understood how search operators support passive reconnaissance.

## Ethical Considerations

All reconnaissance activities should be conducted for educational purposes and within authorised boundaries. Discovering a publicly indexed resource does not grant permission to access, monitor, or interact with it.

Sensitive information, private camera feeds, credentials, and identifiable details should not be shared publicly.

## Conclusion

This exercise provided practical exposure to Google Dorking and the Google Hacking Database as information-gathering techniques. It demonstrated the importance of understanding publicly indexed information and reinforced the need for secure device configurations, responsible reconnaissance, and ethical handling of discovered resources.
